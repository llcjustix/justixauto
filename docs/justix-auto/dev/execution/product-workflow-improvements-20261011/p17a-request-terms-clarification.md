# Initial reservation request versus confirmed terms

Apply the accepted interview's reservation sequence: the supplier confirmation
fixes price/currency, expiry and optional advance/deadline. A dealer request for
future supply may omit not-yet-known desired economic terms; it must not require
an invented price or expiry merely to ask for availability. Source/quantity and
counterparty identity remain validated. No request creates a hold.

Complete economic terms are required for confirmation/activation. If the initial
request did not contain a complete exact matching set, the supplier proposal
requires buyer acceptance of that exact version/digest before activation. An
exact complete requested set can activate on supplier confirmation under the
original rule. No default price, duration, advance or acceptance is introduced.
This is application-hub clarification of the already accepted request/confirm
sequence, not a change to agreed payment/expiry policy.
